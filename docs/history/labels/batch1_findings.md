# Batch 1: blind labels (40 generated foley sounds)

The listener labelled 40 numbered sounds by ear in the "Foley Cue Labels"
artifact. Graphs: `batch1.json`; labels: `batch1_labels/`. Their note: the
batch was mostly hits and breaths, too little variety.

| Family (graph) | Verdict | Labels heard |
|---|---|---|
| wood hit (`modal` wood, noise 0.4-0.75) | 3 good, 1 ok | placing down a plastic bin; hitting a wall / light rock; dowel on a desk |
| layered wood hit (crack + wood modal + thud + `finish`) | 2 good, 1 bad (stone, hissy) | medium-large wooden object; satisfying button press |
| wood knocks (wood bar, noise 0.5-0.7) | 2 good, 1 ok | rhythmic knock; mechanical keyboard keys |
| `click`, noise 0.6-0.8, soft | 2 good, 2 ok | snapped fingers; game switch; spacebar |
| `crumple` (any) | 3 bad, 1 ok | "electric peeing noise" (broken) |
| `rolling` -> `modal` | 2 bad, 1 ok | beast / dragon breath (reads as a breath, not rolling) |
| `friction` -> `modal` | 2 bad, 1 ok | snoring; rubbing on carpet |
| glass shell, metal plate with glide | mostly bad | noisy digital clink; noisy tonal pop |
| `footstep` gravel / concrete | bad / ok | beads shaking; 909 snare; wood step: a suitcase latch |

To do: fix `crumple`; `rolling` + `modal` is a usable creature breath, not
rolling; next batch needs variety (textures, loops, whooshes, machines, UI,
water, cloth) beyond hits.
